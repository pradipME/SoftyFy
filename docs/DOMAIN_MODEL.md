# Domain Model

SoftyFy is a personal music streaming app. This document describes the domain model implemented in Phase 2.

## Entities

| Entity | Table | Description |
| --- | --- | --- |
| `Artist` | `artist` | An artist/performer. Resolved-or-created by name when a song is added. |
| `Album` | `album` | An album/collection, optionally linked to a single artist. |
| `Song` | `song` | A song/track. Has zero or many artists (many-to-many), an optional album, and zero or many `AudioFile`s. |
| `AudioFile` | `audio_file` | A concrete encoded file for a song (e.g. `mp3` 128 kbps, `flac` 1411 kbps). One-to-many with `Song`. |
| `Playlist` | `playlist` | A named, ordered list of songs. |
| `PlaylistSong` | `playlist_song` | Join/order entry between `Playlist` and `Song`, carrying a `position`. |
| `Favorite` | `favorite` | Marks a song as liked. One per song (PK = `song_id`). |

## Relationships

- `Song` N — M `Artist` via `song_artist`.
- `Album` 1 — N `Song` (a song has at most one album).
- `Artist` 1 — N `Album` (optional).
- `Song` 1 — N `AudioFile` (one-to-many). At most one file per song is primary.
- `Playlist` 1 — N `PlaylistSong`; `Song` 1 — N `PlaylistSong` (composite key `(playlist_id, song_id)`).
- `Favorite` — one-to-one with `Song` (PK = `song_id`).

## Identifiers and Auditing

- All identifiers are **UUID v7** (time-ordered) generated by Hibernate
  (`@UuidGenerator(style = UuidGenerator.Style.TIME)`).
- `Favorite` uses the song's id directly as its primary key (`@MapsId`).
- All top-level entities extend `AuditableEntity` (`@MappedSuperclass`), which
  records `created_at` and `updated_at` via Spring Data JPA auditing
  (`JpaAuditingConfig` supplies an `Instant`-based `DateTimeProvider`).

## Package Layout

```
com.softyfy
├── common          # cross-cutting: api (PageResponse), config, entity, exception
├── artist          # Artist + ArtistService + ArtistController + dto
├── album           # Album + AlbumService + AlbumController + dto
├── song            # Song, AudioFile, SongService, SongController, SongMapper + dto
├── playlist        # Playlist, PlaylistSong, PlaylistService, PlaylistController + dto
├── favorite        # Favorite, FavoriteService, FavoriteController + dto
└── storage         # AudioStorage boundary (no provider yet)
```

## Mapping

`SongMapper` normalizes output ordering:
- artists are sorted case-insensitively by name;
- audio files are sorted with the primary file first, then by creation time.
